This project is being built for the NVIDIA x Nebius Global AI Hackathon.

TARGET MODEL:

Use NVIDIA Nemotron 3.5 Lightning through Nebius Token Factory.

NEBIUS_MODEL=

nvidia/Nemotron-3_5-Lightning

PROJECT GOAL
==================================================

Build an autonomous AI internship research and application assistant.

A user should be able to:

1. Upload their resume.
2. Extract and structure their profile.
3. Search for internships.
4. Analyze internship descriptions.

The application must feel like a real product, not a chatbot demo.
